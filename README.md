# 보송함 🧶

뜨개 도안 PDF를 모아두고, 어디까지 떴는지 표시하고, 단수를 세는 아이패드용 앱이에요.

## 할 수 있는 것

- **도안 보관함**: PDF 도안을 여러 개 추가하고 표지 미리보기로 모아 봐요. `전체 / 뜨는 중 / 완성`으로 나눠 볼 수 있어요.
- **진행 위치 표시**: 도안을 **두 번 톡톡** 누르면 그 줄에 노란 형광펜 줄이 생겨요.
  - 줄을 끌어서 옮기기
  - `▲ ▼` 버튼으로 한 줄씩 이동 (줄 굵기만큼 움직여요)
  - 아래쪽 손잡이를 끌어서 굵기를 도안 한 줄 높이에 맞추기
  - `지난 부분 흐리게`로 이미 뜬 부분을 흐리게 하기
  - `📍 표시 위치`로 표시해 둔 곳으로 바로 가기
- **숫자 카운터**: 도안마다 따로 저장돼요. 큰 `＋` 버튼, 카운터 여러 개(단, 코, 무늬 반복 등), 이름 바꾸기, 숫자 직접 입력, 0으로 되돌리기.
- 확대/축소, 마지막으로 보던 위치 기억, 도안을 보는 동안 화면 꺼짐 방지(지원하는 iPadOS에서).
- 가로 모드에서는 카운터가 오른쪽에, 세로 모드에서는 아래쪽에 나와요.
- 한 번 열고 나면 인터넷 없이도 열려요.

모든 도안과 기록은 **아이패드 안에만** 저장돼요. 어디에도 업로드되지 않아요.

## 아이패드에 설치하기

1. 이 저장소를 GitHub Pages로 공개해요: 저장소 **Settings → Pages → Build and deployment**에서
   Source를 `Deploy from a branch`로, 브랜치를 이 앱이 있는 브랜치 / `(root)`로 고르고 저장해요.
   잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생겨요.
2. 아이패드 **Safari**에서 그 주소를 열어요.
3. 공유 버튼(□↑) → **홈 화면에 추가**를 눌러요.
4. 홈 화면의 **보송함** 아이콘으로 앱을 열고, 거기서 `＋ 도안 추가`로 PDF를 넣어요.

> ⚠️ 꼭 **홈 화면 아이콘으로 연 앱 안에서** 도안을 추가해 주세요.
> Safari 탭과 홈 화면 앱은 저장 공간이 따로라서, Safari에서 넣은 도안은 앱에 보이지 않아요.
> 홈 화면 앱을 지우면 저장된 도안과 기록도 함께 지워져요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 앱 화면과 동작 |
| `sw.js`, `manifest.webmanifest` | 홈 화면 앱 / 오프라인 실행 |
| `icons/` | 앱 아이콘 |
| `vendor/pdfjs/` | PDF 표시 라이브러리 [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 (Apache-2.0, 한글 도안용 CMap 포함) |

빌드 과정 없이 정적 파일만으로 동작해요. 컴퓨터에서 확인하려면 이 폴더에서
`python3 -m http.server` 실행 후 `http://localhost:8000`을 열면 돼요.
